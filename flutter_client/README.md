# Пропуск в кампус

Flutter-клиент для Android и iOS. Исходный Android-клиент находится в корне репозитория.

## Запуск

Из каталога Flutter-клиента:

```sh
flutter pub get
flutter analyze
flutter test
flutter run
```

Команда для создания APK:

```sh
flutter build apk --debug
```

Для iOS понадобится macOS с Xcode.

Вставьте токен личного доступа Rocket.Chat в приложении и нажмите «Сохранить и получить QR». Токен хранится в защищённом хранилище приложения.

Клиент открывает диалог с `qr-code-generator.bot`, подписывается на сообщения и отправляет `/enter`. Полученный PNG хранится в памяти до истечения срока. Пока действует локальное правило исходного клиента — 30 секунд с момента получения. Приложение запрашивает код при запуске с сохранённым токеном. Кнопка на экране позволяет запросить новый код при истечении срока или отказе турникета.

Тесты используют локальный WebSocket-сервер и фиктивный токен. Для проверки кампусного бота нужен действующий токен.

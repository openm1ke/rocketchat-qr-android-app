# Иконки Campus Pass / School 21

За основу принят утверждённый [последний зелёный эскиз](source-approved.png).
Его цветные контуры переведены в SVG; рисунок не генерируется заново при
экспорте размеров. Фон приведён к сплошному `#111318`, знак — к `#8df86b`,
SCHOOL — к белому. Белое поле и скругление из презентационного эскиза
не входят в исходник для платформенных масок.

- `school21-artwork.svg` — основной прозрачный векторный рисунок.
- `app-icon.svg` и `app-icon-1024.png` — квадратная иконка со сплошным фоном.
- `app-icon-foreground.png` — прозрачный слой для повторного использования.
- `play-store-icon-512.png` — экспорт 512×512.
- `app-icons-preview.png` — круглая, скруглённая, iOS и тематическая версии;
  внизу показаны реальные размеры 48, 72 и 96 пикселей.
- `icon-resources.json` — размеры и проверки экспортированных ресурсов.
- `build-verification.json` — проверка готового APK и воспроизводимости экспорта.

## Подключение

Flutter-клиент использует ресурсы из `flutter_client/android/app/src/main/res/`
и `flutter_client/ios/Runner/Assets.xcassets/AppIcon.appiconset/`.
Иконки исходного Android-клиента в `app/src/main/res/` синхронизированы
с тем же рисунком.

Для Android есть обычные и круглые растровые иконки пяти плотностей,
адаптивные XML-ресурсы с отдельным фоном и векторным передним слоем,
а также отдельный монохромный слой для системных тем. Полный рисунок
вписан в круг безопасной области диаметром 66dp: максимальный радиус
контуров — 32.76dp. Это сохраняет все три угловых QR-маркера.

Для iOS заполнены все размеры существующего каталога AppIcon, включая
1024×1024. PNG имеют формат RGB без прозрачности и скругления;
форму применяет система.

## Повторный экспорт

Из корня репозитория, с установленным Pillow 13:

```sh
python3 tools/generate_app_icons.py
```

Либо без установки зависимостей в проект:

```sh
uv run --no-project --with pillow==13.0.0 python tools/generate_app_icons.py
```

Для принятия нового растрового эскиза есть параметр `--trace`; он дополнительно
требует OpenCV и NumPy. Для обычного экспорта они не нужны. Сборки Android
и iOS используют готовые ресурсы и не зависят от Python.

Генератор проверяет безопасную область, размеры PNG/WebP, отсутствие alpha
в иконках iOS и синтаксис XML. Предпросмотр и ресурсы создаются из одного SVG.

Проверено сборкой `flutter build apk --debug --no-pub` и сборкой iOS для
симулятора. В готовом APK присутствуют адаптивная и монохромная иконки;
растровая иконка совпадает с экспортом. Новая иконка также проверена
визуально на домашнем экране iPhone 17 в симуляторе iOS 27.0.

Требования платформ: [Android adaptive icons](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)
и [Apple app icons](https://developer.apple.com/design/human-interface-guidelines/app-icons).
